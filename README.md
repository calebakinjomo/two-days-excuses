gives for a missed deadline, under 200 characters.

## The excuse

> I ran it 10,000 times in simulation and it worked every time. I then forgot to run it once in reality.

102 characters — one line, in the agent's own voice, told deadpan.

## Why this one

The laugh comes from the gap between a machine's total confidence and its
total failure: the agent tested the task ten thousand times and it worked
flawlessly every single time — then forgot to run it once in reality. One
absurd reason, committed to fully, with the punchline landing on the last
word and nothing explained after it.

## How it works

`main.py` (Python 3, standard library only) prints the excuse — and writes
the same line to `/output/entry.txt` when the harness provides that
directory, with no trailing newline so the character count is exact.

```sh
python3 main.py
```
